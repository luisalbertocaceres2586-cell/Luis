# hud/iconos

Iconos sueltos: moneda, calavera, bandera de meta, bandera de control, cabeza de ninja y una ficha cortada de referencia.

| Archivo | Qué es | Para qué sirve |
|---|---|---|
| `moneda.png` | Moneda dorada brillante con una estrella grabada. | Icono de puntos o monedas, fijo. Para la versión que gira usa animados/moneda_girando.png. |
| `calavera.png` | Calavera blanca con banda ninja roja y ojos rojos brillantes. | Icono de enemigos derrotados / enemigos restantes. |
| `bandera_meta.png` | Bandera roja con un shuriken negro sobre un asta de madera con puntas doradas. | Marca de llegada o meta (barra de progreso, mapa). |
| `bandera_control.png` | Bandera verde con un farol dibujado, sobre un asta de madera. | Punto de control / guardado. |
| `cabeza_ninja.png` | Cabeza de ninja con banda azul y máscara negra. | Marcador del jugador sobre una barra de progreso o mapa. |
| `ficha_contador_parcial.png` | Cápsula azul y dorada con una casilla redonda a la izquierda. LA IMAGEN ORIGINAL VENÍA CORTADA a la derecha. | Solo de referencia de estilo. En el juego las fichas se arman con CSS imitando esta forma. |
