# Qué animación usar en cada situación

| Situación | Animación |
|---|---|
| Quieta en el suelo | `idle` |
| Moverse despacio | `walk` |
| Moverse rápido | `run` |
| Pulsar salto / subiendo | `jump` o `jump_rise` |
| En el aire cayendo | `jump_fall` |
| Tocar el suelo tras caer | `land` |
| Mantener salto en el aire (planeo) | `glide_start` → `glide` |
| Caída tras planear | `fall` |
| Agacharse / quieta agachada | `crouch_enter` → `crouch` |
| Moverse agachada | `crawl` |
| Deslizarse corriendo | `slide` |
| Esquiva rápida | `dash` |
| Pegada a pared | `wall_grab` |
| Bajar por pared | `wall_slide` |
| Subir por pared | `wall_climb` |
| Saltar desde pared | `wall_jump` |
| Ataque con katana | `melee` (golpes en frames 3,4,6,8,9) |
| Lanzar kunai | `kunai` (proyectil en frames 2-3) |
| Técnica especial | `special` (liberación en frames 7-8) |
| Recibir daño | `hurt` |
| Morir | `death` (no vuelve a idle) |
| Victoria | `win` |
